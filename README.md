# Pulau - notch untuk Android

Fitur: notch kecil di tepi atas layar. Ketuk untuk membuka.
- Jam, atau judul lagu yang sedang diputar
- Musik: judul, artis, progres, tombol sebelumnya/putar-jeda/berikutnya
- Timer fokus (25 menit fokus / 5 menit istirahat)
- Pengingat minum (tiap 1 jam, jam 08.00-21.59) + pencatat air harian

## Cara dapat APK (tanpa Android Studio)
1. Buat repo baru di GitHub (boleh private), unggah semua isi folder ini (termasuk folder .github).
2. Buka tab Actions > "Build APK" > Run workflow (atau otomatis jalan setelah push).
3. Setelah hijau, buka run-nya, unduh artifact "Pulau-APK" di bagian bawah, ekstrak, dapat app-debug.apk.
4. Kirim ke HP, instal (izinkan "instal dari sumber ini").

## Cara lain: Android Studio
File > Open folder ini > tunggu sync > Build > Build APK(s).

## Setelah instal
Buka Pulau, ikuti Langkah 1-3, lalu "Aktifkan Pulau".
